# Task Foundation Test Examples

Task API ทุกเส้นในชุดนี้ต้องมี:

- `prasankit_session` cookie จาก login
- header `X-Workspace-Slug`
- backend resolve `tenant_id` จาก Tenant Context เท่านั้น
- request body และ response ห้ามใช้ `tenant_id`

## List Tasks

Endpoint:

```text
GET /api/v1/workspace/projects/{project_id}/tasks?page=1&limit=10
```

Success:

```json
{
  "data": {
    "items": [
      {
        "id": "task-uuid",
        "project_id": "project-uuid",
        "no": "TASK-0001",
        "title": "Prepare proposal",
        "status": "todo",
        "priority": "medium"
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 10,
      "total": 1,
      "total_pages": 1,
      "has_more": false
    }
  }
}
```

หมายเหตุ:

- ตอนนี้ list เฉพาะ tasks ที่ยังไม่ soft delete
- ต้องมี permission `workspace.view`

## Create Task

Endpoint:

```text
POST /api/v1/workspace/projects/{project_id}/tasks
```

Body:

```json
{
  "title": "Prepare proposal",
  "priority": "high",
  "assignee_member_id": "project-member-uuid",
  "description": "Draft proposal for review",
  "start_date": "2026-05-01",
  "due_date": "2026-05-07"
}
```

Success:

```json
{
  "data": {
    "id": "task-uuid",
    "project_id": "project-uuid",
    "no": "TASK-0001",
    "title": "Prepare proposal",
    "status": "todo",
    "priority": "high",
    "assignee_member_id": "project-member-uuid",
    "description": "Draft proposal for review",
    "start_date": "2026-05-01",
    "due_date": "2026-05-07"
  }
}
```

หมายเหตุ:

- `priority` ถ้าไม่ส่ง จะ default เป็น `medium`
- `assignee_member_id` ถ้าส่ง ต้องเป็น active project member ใน project เดียวกัน
- `no` generate จาก `task_counters` ใน transaction
- ต้องมี permission `workspace.manage`

## Get Task

Endpoint:

```text
GET /api/v1/workspace/projects/{project_id}/tasks/{task_id}
```

Success:

```json
{
  "data": {
    "id": "task-uuid",
    "project_id": "project-uuid",
    "no": "TASK-0001",
    "title": "Prepare proposal",
    "status": "todo",
    "priority": "high"
  }
}
```

หมายเหตุ:

- backend query ด้วย `tenant_id` จาก Tenant Context, `workspace_id` จาก Tenant Context, `project_id` จาก path และ `task_id` จาก path
- ต้องมี permission `workspace.view`

## Common Errors

Invalid project id:

```json
{
  "error": {
    "code": "PROJECT_ID_INVALID",
    "message": "Project id is invalid"
  }
}
```

Invalid task id:

```json
{
  "error": {
    "code": "TASK_ID_INVALID",
    "message": "Task id is invalid"
  }
}
```

Task title required:

```json
{
  "error": {
    "code": "TASK_TITLE_REQUIRED",
    "message": "Task title is required"
  }
}
```

Invalid priority:

```json
{
  "error": {
    "code": "TASK_PRIORITY_INVALID",
    "message": "Task priority is invalid"
  }
}
```

Assignee not found:

```json
{
  "error": {
    "code": "TASK_ASSIGNEE_NOT_FOUND",
    "message": "Task assignee not found"
  }
}
```

Task not found:

```json
{
  "error": {
    "code": "TASK_NOT_FOUND",
    "message": "Task not found"
  }
}
```
