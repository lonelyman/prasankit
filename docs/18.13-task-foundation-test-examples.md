# Task Foundation Test Examples

Task API ทุกเส้นในชุดนี้ต้องมี:

- `prasankit_session` cookie จาก login
- header `X-Workspace-Slug`
- backend resolve `tenant_id` จาก Tenant Context เท่านั้น
- request body และ response ห้ามใช้ `tenant_id`

## List Tasks

Endpoint:

```text
GET /api/v1/workspace/projects/{project_id}/tasks?page=1&limit=10
```

Query filters:

```text
status=todo|in_progress|blocked|done|cancelled
priority=low|medium|high
assignee_member_id=project-member-uuid
```

Success:

```json
{
  "data": {
    "items": [
      {
        "id": "task-uuid",
        "project_id": "project-uuid",
        "no": "TASK-0001",
        "title": "Prepare proposal",
        "status": "todo",
        "priority": "medium"
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 10,
      "total": 1,
      "total_pages": 1,
      "has_more": false
    }
  }
}
```

หมายเหตุ:

- ตอนนี้ list เฉพาะ tasks ที่ยังไม่ soft delete
- filter ทุกตัว optional และทำงานร่วมกันได้
- ต้องมี permission `workspace.view`

## Task Board Summary

Endpoint:

```text
GET /api/v1/workspace/projects/{project_id}/tasks/summary
```

Success:

```json
{
  "data": {
    "project_id": "project-uuid",
    "total": 3,
    "counts": {
      "todo": 2,
      "in_progress": 1,
      "blocked": 0,
      "done": 0,
      "cancelled": 0
    }
  }
}
```

หมายเหตุ:

- นับเฉพาะ tasks ที่ยังไม่ soft delete
- response คืน key ทุก status เพื่อให้ frontend render board columns ได้เสถียร
- ต้องมี permission `workspace.view`

## Create Task

Endpoint:

```text
POST /api/v1/workspace/projects/{project_id}/tasks
```

Body:

```json
{
  "title": "Prepare proposal",
  "priority": "high",
  "assignee_member_id": "project-member-uuid",
  "description": "Draft proposal for review",
  "start_date": "2026-05-01",
  "due_date": "2026-05-07"
}
```

Success:

```json
{
  "data": {
    "id": "task-uuid",
    "project_id": "project-uuid",
    "no": "TASK-0001",
    "title": "Prepare proposal",
    "status": "todo",
    "priority": "high",
    "assignee_member_id": "project-member-uuid",
    "description": "Draft proposal for review",
    "start_date": "2026-05-01",
    "due_date": "2026-05-07"
  }
}
```

หมายเหตุ:

- `priority` ถ้าไม่ส่ง จะ default เป็น `medium`
- `assignee_member_id` ถ้าส่ง ต้องเป็น active project member ใน project เดียวกัน
- `no` generate จาก `task_counters` ใน transaction
- ต้องมี permission `workspace.manage`

## Create Task Comment

Endpoint:

```text
POST /api/v1/workspace/projects/{project_id}/tasks/{task_id}/comments
```

Body:

```json
{
  "body": "Please review this before sending."
}
```

Success:

```json
{
  "data": {
    "id": "comment-uuid",
    "task_id": "task-uuid",
    "body": "Please review this before sending.",

    "created_at": "2026-05-01T10:30:00Z",
    "updated_at": "2026-05-01T10:30:00Z"
  }
}
```

หมายเหตุ:

- API trim body ก่อนบันทึก และไม่รับ body ว่าง
- เขียน activity `updated` พร้อม metadata `action=comment_created`
- ต้องมี permission `workspace.manage`

## Create Task Attachment Upload

Endpoint:

```text
POST /api/v1/workspace/projects/{project_id}/tasks/{task_id}/attachments/uploads
```

Body:

```json
{
  "file_name": "spec.pdf",
  "content_type": "application/pdf",
  "size_bytes": 1024
}
```

Success:

```json
{
  "data": {
    "attachment": {
      "id": "attachment-uuid",
      "task_id": "task-uuid",
      "file_name": "spec.pdf",
      "content_type": "application/pdf",
      "size_bytes": 1024,
      "status": "pending",
      "uploaded_by": "account-uuid",
      "created_at": "2026-05-01T10:30:00Z"
    },
    "upload_url": "http://localhost:19000/...",
    "expires_at": "2026-05-01T10:45:00Z"
  }
}
```

หมายเหตุ:

- API สร้าง metadata เป็น `pending` แล้วคืน presigned PUT URL ให้ client upload ตรงไป MinIO
- object key อยู่หลัง backend เท่านั้น ไม่เปิดใน response
- ต้องมี permission `workspace.manage`

## Update Task

Endpoint:

```text
PATCH /api/v1/workspace/projects/{project_id}/tasks/{task_id}
```

Body:

```json
{
  "title": "Prepare proposal v2",
  "priority": "medium",
  "assignee_member_id": "",
  "description": "Updated proposal scope",
  "start_date": "2026-05-02",
  "due_date": "2026-05-09"
}
```

Success:

```json
{
  "data": {
    "id": "task-uuid",
    "project_id": "project-uuid",
    "no": "TASK-0001",
    "title": "Prepare proposal v2",
    "status": "todo",
    "priority": "medium",
    "description": "Updated proposal scope",
    "start_date": "2026-05-02",
    "due_date": "2026-05-09"
  }
}
```

หมายเหตุ:

- PATCH รองรับ `title`, `priority`, `assignee_member_id`, `description`, `start_date`, `due_date`
- ส่ง `assignee_member_id: ""` เพื่อ clear assignee
- ส่ง `start_date: ""` หรือ `due_date: ""` เพื่อ clear วันที่
- ยังไม่เปลี่ยน `status` ผ่าน PATCH; ให้ใช้ status endpoint แยก
- ต้องมี permission `workspace.manage`

## Update Task Status

Endpoint:

```text
PATCH /api/v1/workspace/projects/{project_id}/tasks/{task_id}/status
```

Body:

```json
{
  "status": "in_progress"
}
```

Success:

```json
{
  "data": {
    "id": "task-uuid",
    "project_id": "project-uuid",
    "no": "TASK-0001",
    "title": "Prepare proposal v2",
    "status": "in_progress",
    "priority": "medium"
  }
}
```

Allowed status:

```text
todo
in_progress
blocked
done
cancelled
```

หมายเหตุ:

- ถ้าเปลี่ยนเป็น `done` backend จะตั้ง `completed_date` เป็นวันที่ปัจจุบัน
- ถ้าเปลี่ยนออกจาก `done` backend จะ clear `completed_date`
- ต้องมี permission `workspace.manage`
