# Auth Me Test Examples

เอกสารนี้เป็นตัวอย่างทดสอบ backend endpoint สำหรับตรวจ session ปัจจุบัน

Endpoint:

```text
GET /api/v1/auth/me
```

Base URL local:

```text
http://localhost:8080
```

## Before Testing

ต้อง login และเก็บ cookie ก่อน:

```bash
curl -i -c /tmp/prasankit-cookie.txt -X POST http://localhost:8080/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -H 'User-Agent: prasankit-manual-test' \
  -d '{
    "email": "owner@example.test",
    "password": "correct-password"
  }'
```

## Behavior

เส้นนี้ใช้ตรวจว่า request ปัจจุบัน login อยู่เป็น account ไหน

ทำแล้ว:

- อ่าน session token จาก httpOnly cookie ตาม `SESSION_COOKIE_NAME`
- hash session token ด้วย `SESSION_SECRET`
- ตรวจ session record ใน Redis
- ตรวจ session ยังไม่หมดอายุ
- โหลด `user_accounts` จาก database
- require `user_accounts.status = active`
- response อยู่ใต้ root key `data`

ยังไม่ทำ:

- คืน workspace membership/context
- คืน permission/role
- logout/revoke session

## Success

Request:

```bash
curl -i -b /tmp/prasankit-cookie.txt http://localhost:8080/api/v1/auth/me
```

Expected response:

```http
HTTP/1.1 200 OK
```

```json
{
  "data": {
    "account": {
      "id": "019dd18a-68e9-7393-98ea-d963c7227ae3",
      "primary_email": "owner@example.test",
      "status": "active"
    }
  }
}
```

## Missing Cookie

Request:

```bash
curl -i http://localhost:8080/api/v1/auth/me
```

Expected response:

```http
HTTP/1.1 401 Unauthorized
```

```json
{
  "error": {
    "code": "AUTH_SESSION_REQUIRED",
    "message": "Authentication session is required"
  }
}
```

## Invalid Session

ถ้า cookie มีค่าแต่ Redis ไม่มี session record หรือ session ใช้ไม่ได้

Expected response:

```http
HTTP/1.1 401 Unauthorized
```

```json
{
  "error": {
    "code": "AUTH_SESSION_INVALID",
    "message": "Authentication session is invalid"
  }
}
```

## Expired Session

ถ้า session หมดอายุ

Expected response:

```http
HTTP/1.1 401 Unauthorized
```

```json
{
  "error": {
    "code": "AUTH_SESSION_EXPIRED",
    "message": "Authentication session is expired"
  }
}
```

## Account Inactive

ถ้า account ถูก suspend/disabled หลังจากมี session แล้ว

Expected response:

```http
HTTP/1.1 403 Forbidden
```

```json
{
  "error": {
    "code": "ACCOUNT_INACTIVE",
    "message": "Account is inactive"
  }
}
```
