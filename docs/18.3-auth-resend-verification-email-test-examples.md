# Auth Resend Verification Email Test Examples

เอกสารนี้เป็นตัวอย่างทดสอบ backend endpoint เท่านั้น สถานะ user flow จริงและจุดที่ต้องกลับมาแก้ดูที่ `docs/18.0-auth-flow-status.md`

Endpoint:

```text
POST /api/v1/auth/resend-verification-email
```

Base URL local:

```text
http://localhost:8080
```

## Behavior

เส้นนี้ใช้ขอส่ง verification email ใหม่ กรณี email ไม่ถึงหรือ token หมดอายุ

ทำแล้ว:

- รับ email
- normalize email
- validate email format
- rate limit ต่อ IP
- rate limit ต่อ email
- ถ้า account ไม่มีอยู่ จะตอบ generic success เพื่อไม่เปิดเผย account existence
- ถ้า account verified แล้ว จะตอบ generic success เพื่อไม่เปิดเผย state เกินจำเป็น
- ถ้า account ยัง `pending_verification`:
  - revoke active verification token เก่า
  - create verification token ใหม่
  - ส่ง verification email ผ่าน SMTP จริง
  - create `security_events` เป็น `auth.email_verification_resent`

## Success

Request:

```bash
curl -i -X POST http://localhost:8080/api/v1/auth/resend-verification-email \
  -H 'Content-Type: application/json' \
  -H 'User-Agent: prasankit-manual-test' \
  -d '{
    "email": "owner@example.test"
  }'
```

Expected response:

```http
HTTP/1.1 200 OK
```

```json
{
  "data": {
    "status": "ok"
  }
}
```

Response notes:

- response เป็น generic success ทั้งกรณีส่งจริง ไม่พบ account หรือ account verified แล้ว
- ใช้เพื่อหลีกเลี่ยงการเปิดเผยว่า email มี account ในระบบหรือไม่

## Invalid Email

Request:

```bash
curl -i -X POST http://localhost:8080/api/v1/auth/resend-verification-email \
  -H 'Content-Type: application/json' \
  -d '{
    "email": "not-an-email"
  }'
```

Expected response:

```http
HTTP/1.1 400 Bad Request
```

```json
{
  "error": {
    "code": "INVALID_EMAIL",
    "message": "Email is invalid"
  }
}
```

## Rate Limited

ถ้า IP หรือ email เดิมขอส่งซ้ำเกิน policy

Expected response:

```http
HTTP/1.1 429 Too Many Requests
```

```json
{
  "error": {
    "code": "VERIFICATION_EMAIL_RATE_LIMITED",
    "message": "Too many verification email requests"
  }
}
```

## SMTP Send Failure

ถ้า SMTP provider ล่ม หรือ credential ใน `.env` ไม่ถูกต้อง

Expected response:

```http
HTTP/1.1 502 Bad Gateway
```

```json
{
  "error": {
    "code": "VERIFICATION_EMAIL_SEND_FAILED",
    "message": "Verification email could not be sent"
  }
}
```
