# Auth Logout All Test Examples

Endpoint:

```text
POST /api/v1/auth/logout-all
```

ไม่ต้องส่ง body ใช้ cookie จาก login เหมือน logout ปกติ

## Success

```bash
curl -i -b /tmp/prasankit-cookie.txt -c /tmp/prasankit-cookie.txt \
  -X POST http://localhost:8080/api/v1/auth/logout-all
```

Expected:

```json
{
  "data": {
    "status": "ok"
  }
}
```

สิ่งที่ backend ทำ:

- ตรวจ session ปัจจุบันจาก `prasankit_session`
- หา account จาก session ปัจจุบัน
- revoke active sessions ทั้งหมดของ account นั้นใน `auth_sessions`
- ลบ Redis session records ที่ active ของ account นั้น
- เขียน `security_events` เป็น `auth.logout_all`
- clear current cookie

## Missing Cookie

```http
HTTP/1.1 401 Unauthorized
```

```json
{
  "error": {
    "code": "AUTH_SESSION_REQUIRED",
    "message": "Authentication session is required"
  }
}
```
