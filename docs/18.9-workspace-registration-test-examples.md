# Workspace Registration Test Examples

## Check Slug

Endpoint:

```text
GET /api/v1/workspaces/check-slug?slug=team-one
```

Success:

```json
{
  "data": {
    "slug": "team-one",
    "available": true
  }
}
```

Unavailable example:

```json
{
  "data": {
    "slug": "admin",
    "available": false,
    "reason": "reserved"
  }
}
```

## Register Workspace

ต้อง login ก่อน เพื่อให้ request มี `prasankit_session` httpOnly cookie

Endpoint:

```text
POST /api/v1/workspaces/register
```

Body:

```json
{
  "name": "Team One",
  "slug": "team-one",
  "contact_email": "owner@example.test"
}
```

Success:

```json
{
  "data": {
    "workspace": {
      "id": "workspace-uuid",
      "name": "Team One",
      "slug": "team-one",
      "mode": "demo",
      "status": "active",
      "contact_email": "owner@example.test"
    },
    "membership": {
      "id": "membership-uuid",
      "workspace_id": "workspace-uuid",
      "role": "owner",
      "status": "active"
    }
  }
}
```

หมายเหตุ:

- request body ห้ามส่ง `tenant_id`
- response ไม่ส่ง `tenant_id` ให้ frontend ใช้เป็นค่าควบคุมสิทธิ์
- backend สร้าง `tenant_id` เอง และสร้าง owner membership ให้ account จาก session

## Common Errors

Missing session:

```json
{
  "error": {
    "code": "AUTH_SESSION_REQUIRED",
    "message": "Authentication session is required"
  }
}
```

Slug taken:

```json
{
  "error": {
    "code": "WORKSPACE_SLUG_TAKEN",
    "message": "Workspace slug is already taken"
  }
}
```

## My Workspaces

ใช้หลัง login เพื่อให้ frontend ตัดสินใจ:

- ถ้า `items` ว่าง ให้ไปหน้า create workspace
- ถ้ามี 1 workspace อาจเข้า workspace นั้นอัตโนมัติ
- ถ้ามีหลาย workspace ให้ไปหน้าเลือก workspace

Endpoint:

```text
GET /api/v1/workspaces/me?page=1&limit=10
```

Success:

```json
{
  "data": {
    "items": [
      {
        "workspace": {
          "id": "workspace-uuid",
          "name": "Team One",
          "slug": "team-one",
          "mode": "demo",
          "status": "active",
          "contact_email": "owner@example.test"
        },
        "membership": {
          "id": "membership-uuid",
          "workspace_id": "workspace-uuid",
          "role": "owner",
          "status": "active"
        }
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 10,
      "total": 1,
      "total_pages": 1,
      "has_more": false
    }
  }
}
```

หมายเหตุ:

- ต้องมี `prasankit_session` cookie
- response ไม่ส่ง `tenant_id`
