# Auth Password Reset Test Examples

## Forgot Password

Endpoint:

```text
POST /api/v1/auth/forgot-password
```

Body:

```json
{
  "email": "owner@example.test"
}
```

Success:

```json
{
  "data": {
    "status": "ok"
  }
}
```

หมายเหตุ:

- response เป็น generic success เพื่อไม่เปิดเผยว่า email มี account หรือไม่
- backend ส่ง reset email ไปที่ frontend URL `MAIL_RESET_BASE_URL?token=...`

## Reset Password

Endpoint:

```text
POST /api/v1/auth/reset-password
```

Body:

```json
{
  "token": "paste-token-from-email-link",
  "password": "new-correct-password"
}
```

Success:

```json
{
  "data": {
    "status": "ok"
  }
}
```

ผลหลัง reset สำเร็จ:

- token ถูก mark เป็น `used`
- password hash ถูกเปลี่ยน
- active sessions ของ account ถูก revoke และ Redis session records ถูกลบ
- เขียน `security_events` เป็น `auth.password_reset_success`
