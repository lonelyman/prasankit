# Current Workspace / Tenant Context Test Examples

ใช้หลัง login และหลังมี workspace แล้ว เพื่อให้ backend resolve workspace ปัจจุบันจาก session + workspace slug

## Current Workspace

Endpoint:

```text
GET /api/v1/workspaces/current
```

Headers:

```text
X-Workspace-Slug: team-one
```

ต้องมี `prasankit_session` cookie จาก login

Success:

```json
{
  "data": {
    "workspace": {
      "id": "workspace-uuid",
      "name": "Team One",
      "slug": "team-one",
      "mode": "demo",
      "status": "active",
      "contact_email": "owner@example.test"
    },
    "membership": {
      "id": "membership-uuid",
      "workspace_id": "workspace-uuid",
      "role": "owner",
      "status": "active"
    },
    "context": {
      "workspace_slug": "team-one",
      "role": "owner"
    }
  }
}
```

หมายเหตุ:

- request ห้ามส่ง `tenant_id`
- response ไม่ส่ง `tenant_id`
- backend resolve `tenant_id`, `workspace_id`, `membership_id`, `role` ภายในจาก session + `X-Workspace-Slug`
- ถ้า account ไม่ใช่ member active ของ workspace นั้น ต้องเข้าไม่ได้

## Common Errors

Missing session:

```json
{
  "error": {
    "code": "AUTH_SESSION_REQUIRED",
    "message": "Authentication session is required"
  }
}
```

Missing `X-Workspace-Slug`:

```json
{
  "error": {
    "code": "WORKSPACE_SLUG_REQUIRED",
    "message": "Workspace slug is required"
  }
}
```

Not a workspace member:

```json
{
  "error": {
    "code": "WORKSPACE_ACCESS_DENIED",
    "message": "Workspace access denied"
  }
}
```
