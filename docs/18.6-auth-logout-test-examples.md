# Auth Logout Test Examples

เอกสารนี้เป็นตัวอย่างทดสอบ backend endpoint สำหรับ logout session ปัจจุบัน

Endpoint:

```text
POST /api/v1/auth/logout
```

Base URL local:

```text
http://localhost:8080
```

## Before Testing

ต้อง login และเก็บ cookie ก่อน:

```bash
curl -i -c /tmp/prasankit-cookie.txt -X POST http://localhost:8080/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -H 'User-Agent: prasankit-manual-test' \
  -d '{
    "email": "owner@example.test",
    "password": "correct-password"
  }'
```

ตรวจว่าก่อน logout session ยังใช้ได้:

```bash
curl -i -b /tmp/prasankit-cookie.txt http://localhost:8080/api/v1/auth/me
```

## Behavior

เส้นนี้ใช้ logout session ปัจจุบันเท่านั้น

ทำแล้ว:

- อ่าน session token จาก httpOnly cookie ตาม `SESSION_COOKIE_NAME`
- hash session token ด้วย `SESSION_SECRET`
- อ่าน session record จาก Redis
- update `auth_sessions.status = revoked`
- set `auth_sessions.revoked_at`
- set `auth_sessions.revoked_reason = user_logout`
- เขียน `security_events` เป็น `auth.logout`
- ลบ session record จาก Redis
- clear httpOnly cookie

ยังไม่ทำ:

- logout ทุกอุปกรณ์ (`POST /api/v1/auth/logout-all`)
- list/revoke session รายอุปกรณ์

## Success

Request:

```bash
curl -i -b /tmp/prasankit-cookie.txt -c /tmp/prasankit-cookie.txt \
  -X POST http://localhost:8080/api/v1/auth/logout
```

Expected response:

```http
HTTP/1.1 200 OK
Set-Cookie: prasankit_session=; Max-Age=0; ...
```

```json
{
  "data": {
    "status": "ok"
  }
}
```

หลัง logout แล้ว `/auth/me` ควรใช้ไม่ได้:

```bash
curl -i -b /tmp/prasankit-cookie.txt http://localhost:8080/api/v1/auth/me
```

Expected response:

```http
HTTP/1.1 401 Unauthorized
```

```json
{
  "error": {
    "code": "AUTH_SESSION_REQUIRED",
    "message": "Authentication session is required"
  }
}
```

## Missing Cookie

Request:

```bash
curl -i -X POST http://localhost:8080/api/v1/auth/logout
```

Expected response:

```http
HTTP/1.1 401 Unauthorized
```

```json
{
  "error": {
    "code": "AUTH_SESSION_REQUIRED",
    "message": "Authentication session is required"
  }
}
```

## Invalid Session

ถ้า cookie มีค่าแต่ Redis ไม่มี session record หรือ session ถูก revoke ไปแล้ว

Expected response:

```http
HTTP/1.1 401 Unauthorized
```

```json
{
  "error": {
    "code": "AUTH_SESSION_INVALID",
    "message": "Authentication session is invalid"
  }
}
```
