# Project Team Test Examples

Project Team API ทุกเส้นในชุดนี้ต้องมี:

- `prasankit_session` cookie จาก login
- header `X-Workspace-Slug`
- backend resolve `tenant_id` จาก Tenant Context เท่านั้น
- request body และ response ห้ามใช้ `tenant_id`

## List Project Members

Endpoint:

```text
GET /api/v1/workspace/projects/{project_id}/members?page=1&limit=10
```

Headers:

```text
X-Workspace-Slug: team-one
```

Success:

```json
{
  "data": {
    "items": [
      {
        "id": "project-member-uuid",
        "project_id": "project-uuid",
        "workspace_membership_id": "workspace-membership-uuid",
        "user_account_id": "user-account-uuid",
        "role": "project_owner",
        "status": "active"
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 10,
      "total": 1,
      "total_pages": 1,
      "has_more": false
    }
  }
}
```

หมายเหตุ:

- ใช้ `project_id` จาก response create/list/get project
- response ไม่ส่ง `tenant_id` และไม่ส่ง `workspace_id`
- backend query ด้วย `tenant_id` จาก Tenant Context, `workspace_id` จาก Tenant Context และ `project_id`
- ตอนนี้ list เฉพาะ active project members
- ต้องมี permission `workspace.view`

## Add Project Member

Endpoint:

```text
POST /api/v1/workspace/projects/{project_id}/members
```

Headers:

```text
X-Workspace-Slug: team-one
```

Body:

```json
{
  "workspace_membership_id": "workspace-membership-uuid",
  "role": "member"
}
```

Success:

```json
{
  "data": {
    "id": "project-member-uuid",
    "project_id": "project-uuid",
    "workspace_membership_id": "workspace-membership-uuid",
    "user_account_id": "user-account-uuid",
    "role": "member",
    "status": "active"
  }
}
```

หมายเหตุ:

- `workspace_membership_id` ต้องเป็น active workspace membership ใน workspace ปัจจุบัน
- `role` ถ้าไม่ส่ง จะ default เป็น `member`
- `role` ใช้ master/FK จาก `project_roles`; code ที่ใช้ได้ตอนนี้คือ `project_owner`, `project_manager`, `member`, `finance`, `viewer`
- request body ห้ามส่ง `tenant_id`
- response ไม่ส่ง `tenant_id` และไม่ส่ง `workspace_id`
- backend insert ด้วย `tenant_id` จาก Tenant Context, `workspace_id` จาก Tenant Context และ `project_id`
- เพิ่มคนที่เป็น active project member อยู่แล้วซ้ำไม่ได้
- ต้องมี permission `workspace.manage`

## Common Errors

Missing session:

```json
{
  "error": {
    "code": "AUTH_SESSION_REQUIRED",
    "message": "Authentication session is required"
  }
}
```

Missing `X-Workspace-Slug`:

```json
{
  "error": {
    "code": "WORKSPACE_SLUG_REQUIRED",
    "message": "Workspace slug is required"
  }
}
```

Invalid project id:

```json
{
  "error": {
    "code": "PROJECT_ID_INVALID",
    "message": "Project id is invalid"
  }
}
```

Invalid workspace membership id:

```json
{
  "error": {
    "code": "WORKSPACE_MEMBERSHIP_ID_INVALID",
    "message": "Workspace membership id is invalid"
  }
}
```

Workspace membership not found:

```json
{
  "error": {
    "code": "WORKSPACE_MEMBERSHIP_NOT_FOUND",
    "message": "Workspace membership not found"
  }
}
```

Invalid project role:

```json
{
  "error": {
    "code": "PROJECT_ROLE_INVALID",
    "message": "Project role is invalid"
  }
}
```

Project member already exists:

```json
{
  "error": {
    "code": "PROJECT_MEMBER_ALREADY_EXISTS",
    "message": "Project member already exists"
  }
}
```

Project not found:

```json
{
  "error": {
    "code": "PROJECT_NOT_FOUND",
    "message": "Project not found"
  }
}
```
