# Auth Register Test Examples

Endpoint:

```text
POST /api/v1/auth/register
```

Base URL local:

```text
http://localhost:8080
```

## Before Testing

เริ่มระบบ local:

```bash
make dev-up
```

หรือถ้า infrastructure รันอยู่แล้วและแก้ API code:

```bash
docker compose up -d --build prasankit-api
```

ต้องตั้งค่า SMTP จริงใน `.env` ก่อน เพราะ register จะส่ง verification email จริง:

```env
MAIL_SMTP_HOST=smtp.example.com
MAIL_SMTP_PORT=587
MAIL_SMTP_USERNAME=your_username
MAIL_SMTP_PASSWORD=your_password
MAIL_FROM_ADDRESS=no-reply@example.com
MAIL_FROM_NAME=Prasankit
MAIL_VERIFY_BASE_URL=http://localhost:3000/auth/verify-email
MAIL_VERIFY_TOKEN_TTL=30m
MAIL_VERIFY_IP_LIMIT=5
MAIL_VERIFY_IP_WINDOW=10m
MAIL_VERIFY_EMAIL_SUBJECT=Verify your Prasankit account
```

## Behavior

เส้นนี้ใช้สมัคร account ด้วย email/password

ทำแล้ว:

- รับ JSON body
- normalize email ด้วย trim + lowercase
- validate email format
- validate password ขั้นต่ำ 8 ตัวอักษร
- reject duplicate email
- จำกัดจำนวนการส่ง verify email ต่อ IP ด้วย Redis rate limit
- hash password ด้วย bcrypt
- create `user_accounts`
- create `auth_identities` แบบ `email_password/email`
- create `auth_email_verification_tokens`
- ส่ง verification email ผ่าน SMTP จริง
- create `security_events` เป็น `auth.account_registered`
- create `security_events` เป็น `auth.email_verification_sent`

## Success

Request:

```bash
email="owner-$(date +%s)@example.test"

curl -i -X POST http://localhost:8080/api/v1/auth/register \
  -H 'Content-Type: application/json' \
  -H 'User-Agent: prasankit-manual-test' \
  -d "{
    \"email\": \"${email}\",
    \"password\": \"correct-password\"
  }"
```

Expected response:

```http
HTTP/1.1 201 Created
```

```json
{
  "data": {
    "account": {
      "id": "019dd18a-68e9-7393-98ea-d963c7227ae3",
      "primary_email": "owner-1777337001@example.test",
      "status": "pending_verification"
    },
    "verification_email_sent": true
  }
}
```

Response notes:

- `id` เป็น UUID v7 ที่ Go application สร้างก่อน insert
- `primary_email` เป็น email หลัง normalize แล้ว
- response ไม่ส่ง password หรือ password hash กลับออกมา
- account ใหม่เริ่มด้วย status `pending_verification`
- ระบบสร้าง verification token เก็บเฉพาะ hash ใน database
- verification token ตัวจริงอยู่ใน email link เท่านั้น

## Duplicate Email

ใช้ email เดิมยิงซ้ำ โดยคำสั่งแรกควรได้ `201 Created` และคำสั่งที่สองควรได้ `409 Conflict`

Request:

```bash
email="duplicate-$(date +%s)@example.test"

curl -i -X POST http://localhost:8080/api/v1/auth/register \
  -H 'Content-Type: application/json' \
  -d "{
    \"email\": \"${email}\",
    \"password\": \"correct-password\"
  }"

curl -i -X POST http://localhost:8080/api/v1/auth/register \
  -H 'Content-Type: application/json' \
  -d "{
    \"email\": \"${email}\",
    \"password\": \"correct-password\"
  }"
```

Expected response from second request:

```http
HTTP/1.1 409 Conflict
```

```json
{
  "error": {
    "code": "EMAIL_ALREADY_REGISTERED",
    "message": "Email is already registered"
  }
}
```

## Invalid Email

Request:

```bash
curl -i -X POST http://localhost:8080/api/v1/auth/register \
  -H 'Content-Type: application/json' \
  -d '{
    "email": "not-an-email",
    "password": "correct-password"
  }'
```

Expected response:

```http
HTTP/1.1 400 Bad Request
```

```json
{
  "error": {
    "code": "INVALID_EMAIL",
    "message": "Email is invalid"
  }
}
```

## Password Too Short

Request:

```bash
curl -i -X POST http://localhost:8080/api/v1/auth/register \
  -H 'Content-Type: application/json' \
  -d '{
    "email": "owner@example.test",
    "password": "short"
  }'
```

Expected response:

```http
HTTP/1.1 400 Bad Request
```

```json
{
  "error": {
    "code": "PASSWORD_TOO_SHORT",
    "message": "Password is too short"
  }
}
```

```bash
curl -i -X POST http://localhost:8080/api/v1/auth/register \

  -d '{'
```

Expected response:

```http
HTTP/1.1 400 Bad Request
```

```json
{
  "error": {
    "code": "INVALID_REQUEST",
    "message": "Request body is invalid"
  }

```

## Too Many Verification Emails

ถ้า IP เดียวกันสมัครหลายครั้งเกิน `MAIL_VERIFY_IP_LIMIT` ภายใน `MAIL_VERIFY_IP_WINDOW`

Expected response:

```http
HTTP/1.1 429 Too Many Requests
```

```json
{
  "error": {
    "code": "VERIFICATION_EMAIL_RATE_LIMITED",
    "message": "Too many verification email requests"
  }
}
```

## SMTP Send Failure

ถ้า SMTP provider ล่ม หรือ credential ใน `.env` ไม่ถูกต้อง

Expected response:

```http
HTTP/1.1 502 Bad Gateway
```

```json
{
  "error": {
    "code": "VERIFICATION_EMAIL_SEND_FAILED",
    "message": "Verification email could not be sent"
  }
}
```
