# Auth Verify Email Test Examples

เอกสารนี้เป็นตัวอย่างทดสอบ backend endpoint เท่านั้น ตอนนี้ยังไม่มี frontend page `/auth/verify-email` สถานะ user flow จริงและจุดที่ต้องกลับมาแก้ดูที่ `docs/18.0-auth-flow-status.md`

Endpoint:

```text
POST /api/v1/auth/verify-email
```

Base URL local:

```text
http://localhost:8080
```

## Before Testing

ต้องสมัครผ่าน `POST /api/v1/auth/register` ก่อน แล้วเปิด email ที่ได้รับ

ใน email จะมี link ลักษณะนี้:

```text
http://localhost:3000/auth/verify-email?token=<verification-token>
```

ตอนนี้ frontend ยังไม่ทำ ให้ copy ค่า `<verification-token>` จาก query string แล้วนำมายิง API ด้วย curl

## Behavior

เส้นนี้ใช้ verify email จาก token ที่ส่งใน email

ทำแล้ว:

- รับ JSON body ที่มี `token`
- hash token แล้วหาใน `auth_email_verification_tokens`
- เช็ก token status เป็น `active`
- เช็ก token ยังไม่หมดอายุ
- mark token เป็น `used`
- set `auth_identities.email_verified_at`
- set `user_accounts.status = active`
- create `security_events` เป็น `auth.email_verified`

## Success

Request:

```bash
token="paste-token-from-email-link"

curl -i -X POST http://localhost:8080/api/v1/auth/verify-email \
  -H 'Content-Type: application/json' \
  -H 'User-Agent: prasankit-manual-test' \
  -d "{
    \"token\": \"${token}\"
  }"
```

Expected response:

```http
HTTP/1.1 200 OK
```

```json
{
  "data": {
    "account": {
      "id": "019dd18a-68e9-7393-98ea-d963c7227ae3",
      "primary_email": "owner@example.test",
      "status": "active"
    }
  }
}
```

Response notes:

- token ตัวจริงไม่ถูกเก็บใน database
- database เก็บเฉพาะ token hash
- token ที่ใช้สำเร็จแล้วจะถูก mark เป็น `used`
- account จะเปลี่ยนเป็น `active`

## Token Required

Request:

```bash
curl -i -X POST http://localhost:8080/api/v1/auth/verify-email \
  -H 'Content-Type: application/json' \
  -d '{
    "token": ""
  }'
```

Expected response:

```http
HTTP/1.1 400 Bad Request
```

```json
{
  "error": {
    "code": "VERIFICATION_TOKEN_REQUIRED",
    "message": "Verification token is required"
  }
}
```

## Invalid Token

Request:

```bash
curl -i -X POST http://localhost:8080/api/v1/auth/verify-email \
  -H 'Content-Type: application/json' \
  -d '{
    "token": "invalid-token"
  }'
```

Expected response:

```http
HTTP/1.1 400 Bad Request
```

```json
{
  "error": {
    "code": "VERIFICATION_TOKEN_INVALID",
    "message": "Verification token is invalid"
  }
}
```

## Already Used Token

ใช้ token เดิมยิงซ้ำหลัง verify สำเร็จแล้ว

Expected response:

```http
HTTP/1.1 409 Conflict
```

```json
{
  "error": {
    "code": "VERIFICATION_TOKEN_ALREADY_USED",
    "message": "Verification token is already used"
  }
}
```

## Expired Token

ถ้า token หมดอายุตาม `MAIL_VERIFY_TOKEN_TTL`

Expected response:

```http
HTTP/1.1 400 Bad Request
```

```json
{
  "error": {
    "code": "VERIFICATION_TOKEN_EXPIRED",
    "message": "Verification token is expired"
  }
}
```

## Invalid JSON

Request:

```bash
curl -i -X POST http://localhost:8080/api/v1/auth/verify-email \
  -H 'Content-Type: application/json' \
  -d '{'
```

Expected response:

```http
HTTP/1.1 400 Bad Request
```

```json
{
  "error": {
    "code": "INVALID_REQUEST",
    "message": "Request body is invalid"
  }
}
```
