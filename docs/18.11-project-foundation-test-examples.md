# Project Foundation Test Examples

Project API ทุกเส้นในชุดนี้ต้องมี:

- `prasankit_session` cookie จาก login
- header `X-Workspace-Slug`
- backend resolve `tenant_id` จาก Tenant Context เท่านั้น

## Create Project

Endpoint:

```text
POST /api/v1/workspace/projects
```

Headers:

```text
X-Workspace-Slug: team-one
```

Body:

```json
{
  "name": "Project A",
  "type": "internal",
  "description": "First project",
  "client_or_requesting_unit": "Internal",
  "scope_or_objective": "MVP project tracking"
}
```

Success:

```json
{
  "data": {
    "project": {
      "id": "project-uuid",
      "workspace_id": "workspace-uuid",
      "code": "PRJ-2026-0001",
      "name": "Project A",
      "type": "internal",
      "status": "draft",
      "priority": "medium",
      "description": "First project",
      "client_or_requesting_unit": "Internal",
      "scope_or_objective": "MVP project tracking"
    },
    "member": {
      "id": "project-member-uuid",
      "project_id": "project-uuid",
      "role": "project_owner",
      "status": "active"
    }
  }
}
```

หมายเหตุ:

- request body ห้ามส่ง `tenant_id`
- response ไม่ส่ง `tenant_id`
- project code สร้างจาก backend ผ่าน `project_code_counters`
- project status เริ่มต้นเป็น `draft`
- priority เริ่มต้นเป็น `medium`
- คนสร้างถูกเพิ่มเป็น `project_owner`
- ต้องมี permission `workspace.manage`

## List Projects

Endpoint:

```text
GET /api/v1/workspace/projects?page=1&limit=10
```

Headers:

```text
X-Workspace-Slug: team-one
```

Success:

```json
{
  "data": {
    "items": [
      {
        "project": {
          "id": "project-uuid",
          "workspace_id": "workspace-uuid",
          "code": "PRJ-2026-0001",
          "name": "Project A",
          "type": "internal",
          "status": "draft",
          "priority": "medium"
        },
        "member": {
          "id": "project-member-uuid",
          "project_id": "project-uuid",
          "role": "project_owner",
          "status": "active"
        }
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 10,
      "total": 1,
      "total_pages": 1,
      "has_more": false
    }
  }
}
```

## Common Errors

Missing session:

```json
{
  "error": {
    "code": "AUTH_SESSION_REQUIRED",
    "message": "Authentication session is required"
  }
}
```

Missing `X-Workspace-Slug`:

```json
{
  "error": {
    "code": "WORKSPACE_SLUG_REQUIRED",
    "message": "Workspace slug is required"
  }
}
```

Permission denied:

```json
{
  "error": {
    "code": "PERMISSION_DENIED",
    "message": "Permission denied"
  }
}
```

Project name missing:

```json
{
  "error": {
    "code": "PROJECT_NAME_REQUIRED",
    "message": "Project name is required"
  }
}
```
