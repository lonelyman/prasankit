# Project Foundation Test Examples

Project API ทุกเส้นในชุดนี้ต้องมี:

- `prasankit_session` cookie จาก login
- header `X-Workspace-Slug`
- backend resolve `tenant_id` จาก Tenant Context เท่านั้น

## Create Project

Endpoint:

```text
POST /api/v1/workspace/projects
```

Headers:

```text
X-Workspace-Slug: team-one
```

Body:

```json
{
  "name": "Project A",
  "type": "internal",
  "description": "First project",
  "client_or_requesting_unit": "Internal",
  "scope_or_objective": "MVP project tracking"
}
```

Success:

```json
{
  "data": {
    "project": {
      "id": "project-uuid",
      "workspace_id": "workspace-uuid",
      "code": "PRJ-2026-0001",
      "name": "Project A",
      "type": "internal",
      "status": "draft",
      "priority": "medium",
      "description": "First project",
      "client_or_requesting_unit": "Internal",
      "scope_or_objective": "MVP project tracking"
    },
    "member": {
      "id": "project-member-uuid",
      "project_id": "project-uuid",
      "role": "project_owner",
      "status": "active"
    }
  }
}
```

หมายเหตุ:

- request body ห้ามส่ง `tenant_id`
- response ไม่ส่ง `tenant_id`
- project code สร้างจาก backend ผ่าน `project_code_counters`
- project status เริ่มต้นเป็น `draft`
- priority เริ่มต้นเป็น `medium`
- คนสร้างถูกเพิ่มเป็น `project_owner`
- ต้องมี permission `workspace.manage`

## Get Project Detail

Endpoint:

```text
GET /api/v1/workspace/projects/{project_id}
```

Headers:

```text
X-Workspace-Slug: team-one
```

Success:

```json
{
  "data": {
    "project": {
      "id": "project-uuid",
      "workspace_id": "workspace-uuid",
      "code": "PRJ-2026-0001",
      "name": "Project A",
      "type": "internal",
      "status": "draft",
      "priority": "medium",
      "description": "First project",
      "client_or_requesting_unit": "Internal",
      "scope_or_objective": "MVP project tracking"
    },
    "member": {
      "id": "project-member-uuid",
      "project_id": "project-uuid",
      "role": "project_owner",
      "status": "active"
    }
  }
}
```

หมายเหตุ:

- ใช้ `project_id` จาก response create/list
- request body ห้ามส่ง `tenant_id`
- response ไม่ส่ง `tenant_id`
- backend query ด้วย `tenant_id` จาก Tenant Context, `workspace_id` จาก Tenant Context และ `project_id`
- ต้องมี permission `workspace.view`

## Update Project Profile

Endpoint:

```text
PATCH /api/v1/workspace/projects/{project_id}
```

Headers:

```text
X-Workspace-Slug: team-one
```

Body:

```json
{
  "name": "Project B",
  "type": "client",
  "priority": "high",
  "description": "",
  "client_or_requesting_unit": "Client B",
  "scope_or_objective": "Updated scope"
}
```

Success:

```json
{
  "data": {
    "project": {
      "id": "project-uuid",
      "workspace_id": "workspace-uuid",
      "code": "PRJ-2026-0001",
      "name": "Project B",
      "type": "client",
      "status": "draft",
      "priority": "high",
      "client_or_requesting_unit": "Client B",
      "scope_or_objective": "Updated scope"
    },
    "member": {
      "id": "project-member-uuid",
      "project_id": "project-uuid",
      "role": "project_owner",
      "status": "active"
    }
  }
}
```

หมายเหตุ:

- เป็น partial update ส่งเฉพาะ field ที่ต้องการแก้ได้
- `description`, `client_or_requesting_unit`, `scope_or_objective` ส่งเป็น `""` เพื่อ clear ค่าได้
- `name` ห้ามว่าง
- `type` ใช้ได้เฉพาะ `internal`, `client`
- `priority` ใช้ master/FK จาก `project_priorities`; code ที่ใช้ได้ตอนนี้คือ `low`, `medium`, `high`
- request body ห้ามส่ง `tenant_id`
- response ไม่ส่ง `tenant_id`
- backend update ด้วย `tenant_id` จาก Tenant Context, `workspace_id` จาก Tenant Context และ `project_id`
- ต้องมี permission `workspace.manage`

## Common Errors

Missing session:

```json
{
  "error": {
    "code": "AUTH_SESSION_REQUIRED",
    "message": "Authentication session is required"
  }
}
```

Missing `X-Workspace-Slug`:

```json
{
  "error": {
    "code": "WORKSPACE_SLUG_REQUIRED",
    "message": "Workspace slug is required"
  }
}
```

Permission denied:

```json
{
  "error": {
    "code": "PERMISSION_DENIED",
    "message": "Permission denied"
  }
}
```

Project name missing:

```json
{
  "error": {
    "code": "PROJECT_NAME_REQUIRED",
    "message": "Project name is required"
  }
}
```

Project update has no fields:

```json
{
  "error": {
    "code": "PROJECT_UPDATE_NO_FIELDS",
    "message": "Project update has no fields"
  }
}
```

Invalid project priority:

```json
{
  "error": {
    "code": "PROJECT_PRIORITY_INVALID",
    "message": "Project priority is invalid"
  }
}
```

Invalid project id:

```json
{
  "error": {
    "code": "PROJECT_ID_INVALID",
    "message": "Project id is invalid"
  }
}
```

Project not found:

```json
{
  "error": {
    "code": "PROJECT_NOT_FOUND",
    "message": "Project not found"
  }
}
```
